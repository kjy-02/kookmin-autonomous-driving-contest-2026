# 영상과 시각화 자료

실제 대회 주행 영상은 추후 추가합니다. 현재 차선·신호등·라바콘 시각화는 [프로젝트 README](../README.md#ros-bag-기반-주행-인식-검증)에서 볼 수 있습니다.

## 팀원 영상 업로드 안내

1. 대회 영상을 이 `media/` 폴더에 올리거나, 팀원이 접근할 수 있는 영상 링크를 준비합니다.
2. 파일명은 `competition-morning.mp4`, `competition-afternoon.mp4`처럼 차수를 구분합니다. 실제로 촬영한 영상만 추가합니다.
3. 아래 양식을 복사해 영상 경로와 주요 구간을 적습니다. 주행 기록을 모르면 임의로 작성하지 않습니다.

```markdown
## 오전 또는 오후 주행

- 영상: [주행 영상](업로드한-파일명.mp4)
- 촬영 차수:
- 주행 시간 / 벌점:
- 주요 구간: 출발 00:00 / 라바콘 00:00 / 장애물·추월 00:00
```

파일 크기 때문에 직접 업로드하기 어렵다면 팀 공유용 외부 링크를 사용합니다. 저장소가 비공개여도 외부 영상의 공개 범위는 별도이므로, 영상 서비스에서도 공유 대상을 확인하세요.
