# 실제 대회 주행 영상

팀 321고의 실제 대회일 주행 영상은 추후 이 위치 또는 외부 영상 링크로 추가합니다. 공식 결과는 6위, 주행 시간 146.02초 완주이며 벌점은 라바콘 2개 6초, 주행 방해 차량 추돌 10초, 차선 이탈 후 차량 원위치 조치 5초로 총 21초입니다.

## 권장 구성

```text
media/
├── README.md
├── competition-run-1.mp4
├── competition-run-2.mp4
└── thumbnails/
    └── competition-run-cover.jpg
```

영상마다 다음 정보를 함께 적으면 포트폴리오 증거로 활용하기 좋습니다.

- 촬영 날짜와 오전/오후 차수
- 실제 주행 시간, 벌점, 최종 기록
- 차량 터치·라바콘 접촉 등 특이사항
- 신호 출발, 라바콘, 장애물, 추월, 경로 선택, 결승선의 타임스탬프
- 해당 주행에 사용한 Git commit 또는 release tag
- rosbag이 있다면 영상과 bag의 시간 대응 관계

GitHub 저장소에 직접 올릴 영상이 크다면 Git LFS를 사용하거나 YouTube 등 외부 링크와 썸네일을 README에 연결하는 방식을 권장합니다. 개인 얼굴, 차량의 네트워크 정보, 다른 참가자의 식별 정보는 공개 전 확인해야 합니다.
