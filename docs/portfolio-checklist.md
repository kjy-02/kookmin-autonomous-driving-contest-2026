# 포트폴리오 공개 전 보완 체크리스트

현재 저장소만으로 확인할 수 없는 항목을 추후 사실에 맞게 보완하기 위한 목록입니다.

## 현재 공유 정책

- GitHub 저장소는 비공개(Private)로 유지하며, 팀원 계정만 collaborator로 초대합니다.
- 센서 기록 관련 자료는 시각화 이미지(PNG)만 공유하고, 원본 rosbag과 별도 분석 파일은 업로드하지 않습니다.
- 팀원 계정은 전달받는 대로 추가하며, 공개 전환은 세 팀원의 합의 후 별도로 진행합니다.
- 공개 라이선스는 공개 전환 방침이 정해질 때까지 추가하지 않습니다.
