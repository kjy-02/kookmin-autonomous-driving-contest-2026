# 추후 추가할 기록

팀 구성·기여·대회 결과·최종 파라미터는 [프로젝트 README](../README.md)에 정리했습니다. 다음은 영상 업로드와 개발 과정 보완에 필요한 항목입니다.

## 대회 영상

- [ ] 실제 대회 전체 주행 영상 또는 팀원이 볼 수 있는 영상 링크
- [ ] 출발·라바콘·고정 장애물·추월 등 주요 구간의 타임스탬프
- [ ] 영상의 오전/오후 차수와 해당 주행의 기록·벌점

업로드 위치와 작성 예시는 [영상 추가 안내](../media/README.md)를 참고하세요.

## 개발 과정 보완

- [ ] 대표 문제와 해결 과정: 벽 오인식, 한쪽 라바콘 열 손실, 통합 후 모드 전환 등
- [ ] 변경 전후 비교 이미지 또는 실제 측정한 성능 수치

## 공개 전 확인

현재 비공개 공유 방침을 유지합니다. 공개 전환 시 팀원 동의, 영상 속 식별 정보, 코드·모델·제공 자료의 라이선스와 배포 범위를 확인합니다. [대회 규정 PDF](<../2026년-9회대회-경주진행방법-최종.pdf>)에는 무단 전재·재배포 금지가 명시되어 있으므로 공개 첨부 전에 허용 범위를 확인해야 합니다.
