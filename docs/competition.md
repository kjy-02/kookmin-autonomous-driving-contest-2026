# 2026년 제9회 국민대 자율주행 경진대회 규정 요약

이 문서는 [대회 공식 웹사이트](https://auto-contest.kookmin.ac.kr/)와 저장소에 포함된 **2026-08-24 버전 경주 진행 자료**를 프로젝트 관점에서 요약한 것입니다. 실제 판정에는 반드시 [원본 대회 규정 PDF](<../2026년-9회대회-경주진행방법-최종.pdf>)를 우선 적용해야 합니다.

## 경기 개요

- 공식 명칭: 제9회 국민대학교 자율주행 경진대회 - AI-엣지 챌린지
- 일시: 2026-08-25
- 장소: 국민대 자율주행 스튜디오
- 주최: 국민대학교 SW중심대학사업단, 국민대학교 소프트웨어융합대학
- 주관: 자이트론
- 본선: 오전·오후 각각 1회, 두 기록 중 더 좋은 성적으로 순위 결정
- 기록: 실제 주행 시간 + 벌점 시간
- 주행: 트랙 3바퀴, 총 실제 주행 시간 4분 초과 시 실격(벌점 시간은 4분 제한에 미포함)

## 팀 321고 경기 결과

- 최종 순위: 6위
- 주행 결과: 146.02초 완주
- 대회 당일 실행: 별도 override 없이 `final_drive.launch.py`의 파라미터 사용

| 벌점 항목 | 횟수 | 벌점 |
| --- | ---: | ---: |
| 라바콘 접촉 | 2개 | 6초 |
| 주행 방해 차량 추돌 | 1회 | 10초 |
| 차선 이탈 후 차량 원위치 조치 | 1회 | 5초 |
| **합계** |  | **21초** |

주행 시간 146.02초와 현장 벌점 내역은 제공받은 기록을 각각 그대로 표기했습니다.

## 본선 미션 순서

1. 4구 신호등 앞에서 정지 상태로 대기한다.
2. 빨강에서 녹색으로 바뀌는 신호를 카메라로 인식해 출발한다. 신호 변경 순간부터 시간이 측정된다.
3. 양쪽 실선 안에서 차선을 따라 주행한다. 1·2차선을 고정해서 사용할 필요는 없다.
4. 라바콘 경로를 충돌 없이 통과한다.
5. 고장 차량과 뒤쪽 라바콘으로 구성된 고정 장애물을 피한다.
6. 느리게 달리는 방해 차량이 사용하지 않는 차선으로 추월한다.
7. 1바퀴 이후 신호등에서 직진 또는 지름길을 선택한다. 좌회전 신호는 2바퀴째 또는 3바퀴째에 무작위로 한 번 제시된다.
8. 3바퀴를 완료하고 통과 감지 장치를 세 번째 통과하면 경기가 종료된다.

## 주요 판정과 벌점

| 상황 | 판정 |
| --- | --- |
| 빨간불 출발 | 10초 벌점과 재출발 기회 |
| 녹색 전환 후 1분 안에 출발하지 못함 | 실격 |
| 주행 중 정지 후 1분 안에 재개하지 못함 | 실격 |
| 차량 접촉 | 1회당 5초 벌점, 심판 지시에 따른 원위치가 원칙 |
| 라바콘 접촉 | 개당 3초 벌점 |
| 라바콘 구간 1분 내 미통과 | 실격 |
| 고정 장애물 또는 그 뒤 라바콘 충돌 | 10초 벌점 |
| 방해 차량 추돌 또는 방해 차량에 추돌당함 | 10초 벌점 |
| 3바퀴 실제 주행 시간이 4분 초과 | 실격 |

원본 자료의 차량 접촉 누적 실격 설명은 횟수와 합산 초 표기가 서로 맞지 않는 부분이 있으므로, 이 문서에서는 임의로 해석하지 않았습니다. 해당 기준은 대회 운영진의 최종 설명을 확인해야 합니다.

## 차선과 추월 규정

- 앞바퀴 2개가 동시에 실선 밖으로 나가거나 차량 절반 이상이 실선 밖으로 나간 경우, 또는 직선에서 이탈 상태로 2 m 이상 주행한 경우 원위치 조치 대상입니다.
- 곡선 안쪽에는 지름길성 차선 이탈을 막기 위한 장애물이 배치될 수 있습니다.
- 방해 차량 추월 중에는 양쪽 실선 이탈이 허용되지만, 방해 차량이 사용하지 않는 차선 쪽으로 추월해야 합니다.
- 추월 완료 후 뒷차와 90 cm 이상 떨어졌는데도 계속 차선 밖을 주행하면 차선 이탈로 판정됩니다.

## 소프트웨어 요구와 본 프로젝트의 대응

대회 자료는 차량 소프트웨어를 노트북에서 원격으로 기동하고, 심판이 볼 수 있는 화면에서 `ros2 launch ...` 형식으로 실행할 것을 요구합니다. 본 프로젝트는 모든 기능을 다음 한 명령으로 기동하도록 구성했습니다.

```bash
ros2 launch final_drive final_drive.launch.py
```

| 규정상 목표 | 프로젝트 대응 |
| --- | --- |
| 신호 변경 전 정지 | 초기 녹색 latch와 빨강·노랑 정지 latch |
| 연속 주행 | 차선·라바콘 인식 실패에 짧은 복구 구간을 두되, timeout에는 즉시 정지 |
| 라바콘 충돌 최소화 | 차체 폭·라바콘 반지름·여유 폭을 고려한 근접 보정과 감속 |
| 고정/이동 차량 회피 | 차량 크기 범위의 LiDAR 군집과 벽 제거를 결합한 공통 회피 로직 |
| 추월 후 빠른 복귀 | 원래 장애물 쪽이 일정 시간 비면 정상 차선 추종으로 복귀 |
| 지름길 선택 | 좌회전 신호 인식은 구현했으나 지름길 조향은 구현하지 않아 직진 전략 사용 |
| 안전한 수동 개입 | 키보드 STOP/RUN과 heartbeat 단절 시 정지 |

## 자동화하지 않은 부분

- 주최 측 Gate가 시간을 측정하므로 소프트웨어 내부 경기 시간 측정은 구현하지 않았습니다.
- 체크무늬 검출기는 보관되어 있지만 통합 런치에서는 비활성화되어 있습니다.
